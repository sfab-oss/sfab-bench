---
title: SFab Bench
description: Open a folder, open a STEP, talk. A CAD workbench for the Mac and Quest Browser.
---

SFab Bench is a CAD workbench. It runs on your Mac, hosts the coding agents
already logged in there, and lets Quest Browser join the same process.
