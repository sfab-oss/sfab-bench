---
title: Desktop app
description: Electron starts the server and adds a native folder dialog.
---

```bash
pnpm desktop
```

An Electron window that starts the server for you. No terminal to keep
open, and **Open…** is the real macOS folder chooser.

It is the same app the browser shows. The window loads
`https://127.0.0.1:7322`. A paired Quest joins that origin.

## Download

Take `sfab-bench-<version>-arm64.app.zip` from
[GitHub Releases](https://github.com/sfab-oss/sfab-bench/releases). Unzip,
drag **sfab-bench** to Applications, double-click. Gatekeeper refuses the
first launch (ad-hoc signed, not notarised). Open **System Settings →
Privacy & Security**, scroll to Security, and press **Open Anyway**.
Then double-click again.

## Things worth knowing

**It attaches to a server that is already running.** If `pnpm dev` is up
on `:7322`, `pnpm desktop` shows you that one and leaves it running when
you quit. Otherwise it starts its own.

**Closing the window does not stop the server.** A paired Quest keeps
working. Quit (⌘Q) is what stops it.

**⌘O** opens a folder in this window. Another tab or the Quest stays
where it is.

## Building a `.app`

```bash
pnpm desktop:package
```

Writes the `.app` and `sfab-bench-<version>-arm64.app.zip`. With
`CSC_NAME` it signs with that identity. Without it, ad-hoc.
