---
title: Providers
description: Drive CLIs already logged in on the Mac. No keys in this app.
---

SFab Bench does not hold provider credentials. It drives CLIs already
logged in on the Mac: OpenCode, Codex, Grok, Claude Code. Cursor is in
the picker but a Mac login is not visible to this app yet.

Pick harness, model, and effort in the composer. If the selected harness
is not signed in, the composer shows the CLI to run:

- Codex: `codex login`
- Claude Code: `claude auth login`
- Grok: `grok login`
- OpenCode: `opencode auth login`

Voice input is a separate AI Gateway key. It is not used for those
harnesses.
