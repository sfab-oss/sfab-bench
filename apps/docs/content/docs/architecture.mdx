---
title: Architecture
description: One Node process, two HTTPS clients, library vs viewport, STEP loader.
---

One Node process owns the STEP loader, the harness agents, and sqlite
under `~/.sfab-bench/`. The Mac browser tab and Quest Browser are both
HTTPS clients of that process.

- **Server** is global. It does not live inside a CAD repo.
- **Project** = a directory on the Mac.
- **Document** = a STEP or GLB in that directory.
- **Agent cwd** = the project directory.
- **Library** is shared: file recents, folder recents, thread list,
  messages at rest. The folder a tab is in is the tab's.
- **Viewport is per browser:** loaded file, selection, camera, XR, which
  chat is open.

Auth: loopback is trusted. Anything else on `/api` needs a paired device
token.

STEP → view package is a **loader**, not a project adapter. OpenCascade
compiled to WASM tessellates each solid once into `assembly.json` +
`.tess` under `~/.sfab-bench/cache/`. No Python.

Electron is a shell: same server, same page, plus a native folder
dialog.
